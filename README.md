# LessTube
Ultimate Youtube interface for addictive personality disorder people

Using 
WXT as extension-framework 
https://wxt.dev/guide/installation.html#bootstrap-project

Project aim to revamp YouTube website ui to eliminate all distraction factors like Youtube Shorts, Notifications, Featured Videos leaving a user essentialy with Search and video Box only.

Method: Injecting css & script that will remove and disable all parts wich fetching additional data making youtube much faster.
